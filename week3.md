# HTML/CSS Notes

## Markup
Markup = tags used to make HTML in browsers, which become HTML elements/methods.
Example: `<h1> WAD </h1>`

## XML
XML = Extensible Markup Language

**HTML Syntax:**
- Tag name (opening): `<h1>`
- Content: `BSCCS`
- Tag name (closing): `</h1>`

Example: `<p>BS Computer Science...</p>` → valid HTML
